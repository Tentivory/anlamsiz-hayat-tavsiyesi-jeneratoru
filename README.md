# Anlamsız Hayat Tavsiyesi Jeneratörü

## Bu Kod Nedir?

Bu, insanlığın karşı karşıya olduğu en büyük sorunlardan birini çözmek için tasarlanmış, dünya çapında devrim yaratacak bir yazılımdır. Hayatın anlamını bulmak yerine, tamamen anlamsız, absürt ve işe yaramaz tavsiyeler üreterek zihninizi temizler. Bilimsel araştırmalar (hiç yapılmadı) göstermiştir ki, bu tür tavsiyeler stres seviyesini %420 oranında azaltır.

## Nasıl Çalışır?

1. Python ile çalıştırırsınız.
2. Rastgele bir anlamsız tavsiye alırsınız.
3. Hayatınız değişmez ama gülersiniz.
4. Tekrar çalıştırırsınız.

## Kurulum

```bash
pip install nothing  # Hiçbir şey gerekmez, zaten saf Python
python tavsiye.py
```

## Örnek Çıktı

```
Tavsiye: Sabahları kahve yerine hava iç, daha hafif.
```

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Bu mükemmel. Daha fazla tavsiye eklemek dengeyi bozar.
